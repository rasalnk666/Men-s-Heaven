# MEN'S HEAVEN Website

1. Open `script.js`.
2. Replace `91XXXXXXXXXX` with your WhatsApp number (country code + number, no + or spaces).
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder to GitHub.
4. GitHub: Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
